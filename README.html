Welcome to Contact Grove

One private place for personal contacts, clients, leads, vendors and important conversations.

Get started

1 · Extract Download and unzip the purchase. Keep all app files together.

2 · Open Double-click index.html on a Windows or Mac computer in current Chrome, Edge, Safari or Firefox.

3 · Add In Contacts choose Add contact. Enter the person's details and category. Open their profile to add follow-ups and log interactions.

Open Contact Grove

Find your next step

Overview counts contacts by group and shows upcoming or overdue follow-ups. Contacts has name, company and note search plus category filtering. Follow-ups can be marked Done. Activity is a record of your calls, emails, meetings or messages.

Follow-ups appear inside this app. The download does not send scheduled phone, email or desktop notifications.

Choose your look and language

Settings includes five cohesive light themes, modern, serif or large text, compact/comfortable/spacious spacing, soft/flat cards and high contrast. Restore appearance defaults at any time. English, Spanish, French and German options change navigation and key labels. Explanatory sentences and the contact details you type remain as written.

Back up and move your contacts

Changes save in this browser profile on this device. Download a JSON backup regularly. To transfer, move that file to another device and import it in Settings. Import replaces existing records in that browser after confirmation. CSV export includes the contact list only; it is not a full backup of follow-ups and activity. Clearing browser/site data can erase the local records.

No automatic sync: A phone and laptop show separate records unless you manually transfer a JSON backup. There is no account or shared cloud database.

Offline and phone use

The extracted app opens offline on desktop. For a phone home-screen icon, the customer files need separate HTTPS hosting first. In Safari use Share → Add to Home Screen; in Chrome use Install/Add to Home Screen when offered. Once hosted and loaded, the app shell can be cached where service workers are supported. A public sample demo is separate from your private customer copy.

Troubleshooting

Contacts look blank: Check the same browser/profile and URL, then import your last backup. ZIP shows source files: Extract it and open index.html. Import rejected: Select an unmodified Contact Grove JSON backup. Install option absent: Use HTTPS and a current browser. Data cleared: Import your JSON backup.
