CONTACT GROVE — QUICK START | HARBORNESTDIGITAL

1. Extract the ZIP and keep the files together. Double-click index.html on your Windows or Mac computer in a current Chrome, Edge, Safari or Firefox browser.
2. Add contacts with name, category, phone, email, company, address, tags and notes. Open a profile to add follow-ups and log calls, meetings, messages or emails.
3. On Overview see category totals, due and overdue follow-ups and recent activity. Search names, companies and notes in Contacts; use the category filter.
4. Settings offers five light themes, readable fonts, spacing, card style, high contrast and English, Spanish, French or German navigation/key labels. Your typed entries are not translated.
5. Records save in this browser profile on this device. They do not sync between devices. Clearing browser data can erase them. Export JSON backups regularly; import a backup on another device to transfer. Import replaces that browser's records.
6. Contact CSV export is for viewing/sharing contacts; use JSON for full backup including follow-ups and activity. Follow-ups are in-app records; no automatic device notifications are sent.
7. Extracted desktop files work offline. For a phone home-screen icon, separately host the customer files on HTTPS. A public sample demo is not a private buyer account.

Troubleshooting: If data appears blank, check the browser profile and URL or import your backup. If an import fails, select a Contact Grove JSON backup. If download files appear as code, extract the ZIP and open index.html. For help contact HarborNestDigital via your Etsy order.
